### **Project Details**

**Overview**  
The **XPR MCP Server** project aims to make the **XPR Network blockchain accessible through natural language AI interactions**. Using the **Model Context Protocol (MCP)**, this project connects AI clients (starting with Claude, later ChatGPT) directly to the XPR blockchain — allowing users to *ask* AI to fetch blockchain data, perform transactions, or interact with smart contracts conversationally.  

**Problem it Solves**  
Currently, interacting with the blockchain requires technical understanding, complex wallet interfaces, and manual data queries. This project simplifies that experience by allowing users to perform blockchain actions — such as checking balances, voting for Block Producers, or staking — using natural language.

**State of the Project**  
- Design and integration plan completed.  
- Development ready to begin on a **dedicated XPR MCP Server** prototype.  
- Deployment and testing planned within 1 month for MVP release.
